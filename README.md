# rATA data analysis script 
This repository includes two analyses: one analysis of rATA data in England, and one of wheeled mobility device (wmd) use data from multiple rATA countries. 
Each analysis script completes a descriptive and inferential (odds ratios and 95% CIs) analysis of standardised rATA data at individual level for a single country or group of countries, available from the WHO global health observatory. 
Separate analyses by device type, and where multiple devices can be selected, are also included. 
Common data cleaning steps are included, however the original data should be checked in advance, as steps needed will vary by country. 
Basic summary figures are also included. The code is commented throughout, but please get in touch with any questions.
